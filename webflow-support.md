# Flow AI Video for Webflow Support

Email [support@flowaivideo.org](mailto:support@flowaivideo.org) for help with the Designer Extension. Include the action you tried, the error message, your browser version, and a screenshot with private information removed. Do not send passwords, API keys, or confidential media.

## Common issues

- **No compatible selection:** Select a section or div in Webflow Designer before choosing **Add video**.
- **URL rejected:** Use public HTTPS URLs that point directly to an MP4 file and, optionally, an image file.
- **Video not playing:** Preview or publish the site, then confirm that the media URL works without a login and has not expired.
- **Need to create a video:** Visit [Flow AI Video](https://flowaivideo.org/) separately. Generation is not performed inside Webflow and may require an account or paid plan.
