# Flow AI Video for Webflow: Review Walkthrough

This 2-minute-15-second English-narrated walkthrough uses screenshots from the actual Webflow Designer integration test. It shows the installed app, selecting a container, entering video and poster URLs, inserting the video, checking its attributes, and viewing the published test page.

The extension adds an existing public MP4 video to a Webflow page. It does not generate or host the video. New clips can be created separately at [Flow AI Video](https://flowaivideo.org/).
